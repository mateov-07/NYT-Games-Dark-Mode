# Dark Mode for NYT Games

A Chrome extension that brings a true dark mode to the **New York Times Games** site, plus full control over the colors of the Crossword, Sudoku, Wordle and Connections boards.

NYT only ships dark mode for Wordle. This extension covers the rest of them, including all puzzles, archives and the menus in between, as well as letting you repaint the boards of some games however you like.

## Features

**Dark mode, game by game**
- 20 individual toggles grouped under three master switches (Games, Archives, Misc.), so you can darken everything at once or only the puzzles you actually play.
- Covers the bonus puzzles too — monthly and easy-mode crosswords, the Mini bonus, Connections 3×3 and the Strands bonus.

**Custom board colors**
- 56 individually editable elements across four games: the Crossword (15), Sudoku (16), Wordle (11) and Connections (14).
- An HSV color picker with a hue slider, plus a typable hex field.
- Copy, paste and reset buttons on every element, plus a live preview that recolors the open tab.
- A built-in help dialog that shows graphics of which part of the board represents its element.

**Presets**
- **Display**: follows your dark mode toggles and NYT's own palette (dark mode color choices are taken directly off of the mobile port).
- **Midnight**, **Forest** and **Magma**: three prebuilt themes, resembling blue, green and orange.
- **Three custom slots per game**: each with its own name (up to 14 characters) and swatch color.
- Presets export to a shareable code and can also be imported in, so presets are sharable to others. or drop a prebuilt one into a custom slot to tweak it.

**Settings**
- **Data**: back up every toggle, color and preference as one code, restore from a code, or reset everything to defaults.
- **Behavior**: pick which page and which color panel the popup opens on (or just let it remember where you left off).

## Installation

Download the extension on the Chrome Web Store here!

If you would like to have it on your own machine, here's how you can do that:

1. Unzip the file into a folder
2. Go to `chrome://extensions` on any chromium browser
3. Once there, click the slider button on the top right labeled **Developer mode**
4. Then click the top left button **Load unpacked** and select the unzipped folder
5. Turn on the extension and pin it for accessibility purposes
6. Open any NYT Games page and you are good to go

**Updating:** replace the folder's contents with the new version, then hit the refresh icon on the extension's card in `chrome://extensions`. Your settings are stored in your Chrome profile.

## Bug reports and feedback

 Within the popup, navigate to **Settings → Report a Bug** in the popup: it fills in your version, browser, OS and current page for you, and allows you to type in what happened through  the email speakingblock@gmail.com.

Otherwise, you may open an issue on this repository.
